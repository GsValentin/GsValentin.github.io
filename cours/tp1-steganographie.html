Images & Sécurité : Stéganographie Numérique

Dissimulation par bit de poids faible (LSB), codage RVB/ASCII et impact de la compression (PNG vs JPEG)

BTS SIO SISR • Bloc 3 • Cybersécurité & Codage

1. Stéganographie vs Cryptographie

Bien que complémentaires, ces deux disciplines poursuivent des objectifs distincts :

  • Cryptographie : Rendre un message inintelligible à toute personne ne possédant pas la clé de déchiffrement (l'art du secret — enfermer un message dans un coffre-fort)[cite: 97].
  • Stéganographie : Dissimuler l'existence même d'un message caché au sein d'un fichier anodin comme une image, un son ou une vidéo (l'art de la dissimulation — enterrer le coffre dans le jardin)[cite: 97].

2. Codage RVB & Principe LSB (Least Significant Bit)

Une image numérique est une grille de pixels repérés par leurs coordonnées $(x, y)$[cite: 97]. En codage RVB (Rouge, Vert, Bleu), chaque composante est codée sur 1 octet (de 0 à 255 en décimal, ou 00 à FF en hexadécimal)[cite: 98].

Modifier de +1 ou -1 la valeur d'une composante (par exemple le Bleu) est totalement imperceptible pour l'œil humain[cite: 98]. La technique LSB (bit de poids faible) consiste à remplacer le dernier bit (bit de droite, poids $2^0 = 1$) de la composante couleur par un bit du message secret[cite: 98] :

  • Si le bit à cacher vaut 0 → la composante devient un nombre pair (se termine par 0 en binaire)[cite: 98].
  • Si le bit à cacher vaut 1 → la composante devient un nombre impair (se termine par 1 en binaire)[cite: 98].

3. Méthode d'extraction d'un message caché (GIMP)

Dans une image dissimulant un texte codé en ASCII (8 bits par caractère) sur la composante bleue[cite: 98] :

  1. Lire la longueur $l$ du message : Relever la composante bleue des 8 premiers pixels de la ligne 0 (ordonnée $y = 0$)[cite: 98]. Extraire leur bit de poids faible (pair = 0, impair = 1) pour reconstituer l'octet donnant le nombre de caractères $l$[cite: 98].
  2. Extraire les bits du texte : Sur la ligne 1 (ordonnée $y = 1$), relever la composante bleue des $8 \times l$ premiers pixels et noter leur bit de poids faible[cite: 98].
  3. Convertir en caractères : Regrouper les bits par paquets de 8 (octets), convertir chaque octet en décimal puis lire le caractère correspondant dans la table ASCII[cite: 98].
Raccourcis utiles dans GIMP :
• Zoom maximal (25600%) : Outil Loupe + clic (maintenir Ctrl pour dézoomer) afin de distinguer chaque pixel individuellement[cite: 97].
• Lire la valeur RVB exacte : Outil Pipette + Maj (Shift) + clic sur le pixel ciblé[cite: 98].

4. Choix du format d'image : Compression avec ou sans perte

La survie d'un message caché en LSB dépend directement de l'algorithme de sauvegarde utilisé[cite: 99] :

Format Type de compression Compatibilité Stéganographie LSB
PNG (Portable Network Graphics) Sans perte (Lossless)[cite: 99] Compatible : Conserve la valeur exacte de chaque pixel au bit près[cite: 99].
BMP (Bitmap) Aucune compression (brut)[cite: 99] Compatible : Fichier très volumineux mais intact[cite: 99].
JPEG / JPG Avec perte (Lossy)[cite: 99] Incompatible : L'algorithme modifie légèrement les couleurs voisines pour alléger le fichier, ce qui détruit les bits de poids faible et corrompt le message caché[cite: 99].

Note : Cette technique s'applique également à d'autres supports numériques non compressés avec perte, comme les fichiers audio (WAV) ou vidéo, utilisés parfois en cybersécurité pour dissimuler des charges utiles (malware / exfiltration de données).
