Routage Inter-VLAN Cisco

Router-on-a-stick, sous-interfaces 802.1Q, passerelles par VLAN et commutateur de niveau 3 (Catalyst 3560)

BTS SIO SISR • Cisco Packet Tracer

1. Principe du Router-on-a-Stick

La segmentation par VLAN isole les réseaux au niveau 2 (liaison)[cite: 25]. Pour faire communiquer deux VLANs distincts, il faut un équipement de niveau 3 (routeur ou switch L3) présent dans chaque VLAN[cite: 25, 38, 46].

L'architecture Router-on-a-stick utilise un seul câble physique monté en trunk 802.1Q entre le commutateur (SW1 Gi0/2) et le routeur (R1 Gi0/0)[cite: 25, 30]. Le routeur découpe ensuite son interface physique en autant de sous-interfaces logiques qu'il y a de VLANs à router[cite: 30].

Règle de câblage : Un commutateur et un routeur sont des équipements de nature différente — on les relie avec un câble droit (contrairement à deux commutateurs qui exigent un câble croisé)[cite: 26].

2. Plan des sous-interfaces & Passerelles

Sous-interface R1 VLAN servi Passerelle (.254) Équipements concernés
Gi0/0 (physique) — Aucune adresse IP Port support uniquement (protège le VLAN natif 999)[cite: 26, 34].
Gi0/0.10 10 (DIRECTION) 192.168.10.254/24 PC1 (.11), PC3 (.13)[cite: 27]
Gi0/0.20 20 (COMPTA) 192.168.20.254/24 PC2 (.12), PC4 (.14)[cite: 27]
Gi0/0.99 99 (MGMT) 192.168.99.254/24 PC-ADMIN (.10), SW1 (.1), SW2 (.2)[cite: 27]
Gi0/0.150 150 (VOIX) 192.168.150.254/24 Téléphone IP 7960[cite: 27, 28]
Aucune 999 (MORT) Non routé Le VLAN natif reste volontairement isolé sans passerelle[cite: 27, 28].

3. Configuration du Switch (SW1) & du Routeur (R1)

Côté SW1 : Réveiller Gi0/2 et passer en Trunk

SW1(config)# interface gigabitEthernet 0/2
SW1(config-if)# description Vers R1 trunk inter-VLAN
SW1(config-if)# no shutdown
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk native vlan 999
SW1(config-if)# switchport trunk allowed vlan 10,20,99,150,999

Côté R1 : Allumer Gi0/0 et créer les sous-interfaces

! 1. Activer l'interface physique sans IP
R1(config)# interface gigabitEthernet 0/0
R1(config-if)# no shutdown
R1(config-if)# exit

! 2. Créer chaque sous-interface logique
R1(config)# interface gigabitEthernet 0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.254 255.255.255.0
R1(config-subif)# exit

R1(config)# interface gigabitEthernet 0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.254 255.255.255.0
R1(config-subif)# exit

R1(config)# interface gigabitEthernet 0/0.99
R1(config-subif)# encapsulation dot1Q 99
R1(config-subif)# ip address 192.168.99.254 255.255.255.0
R1(config-subif)# exit

R1(config)# interface gigabitEthernet 0/0.150
R1(config-subif)# encapsulation dot1Q 150
R1(config-subif)# ip address 192.168.150.254 255.255.255.0
R1(config-subif)# end
Point critique : Le numéro après le point (Gi0/0.10) n'est qu'une convention de nommage[cite: 34, 35]. C'est uniquement la commande encapsulation dot1Q 10 qui associe réellement la sous-interface aux trames étiquetées du VLAN 10[cite: 35].

4. Passerelle des commutateurs de niveau 2

Un commutateur de niveau 2 (Catalyst 2960) ne route pas[cite: 25, 40]. Pour qu'il puisse répondre à un ping ou une session SSH provenant d'un autre VLAN que son VLAN de management (VLAN 99), il doit connaître sa passerelle par défaut[cite: 39, 40] :

SW1(config)# ip default-gateway 192.168.99.254

(À appliquer également sur SW2[cite: 40]. Cette commande est ignorée sur un commutateur de niveau 3 ayant ip routing activé[cite: 40]).

5. Alternative : Commutateur de Niveau 3 (Catalyst 3560)

En Router-on-a-stick, chaque paquet inter-VLAN franchit deux fois le même câble physique (effet demi-tour / hairpin), divisant par deux la bande passante utile du lien[cite: 43]. Un commutateur de niveau 3 élimine ce goulot d'étranglement en routant directement en interne via des interfaces virtuelles (SVI)[cite: 44, 45, 46] :

! Activer la fonction routage du switch L3
SW-L3(config)# ip routing

! Créer les passerelles SVI (pas besoin d'encapsulation dot1Q)
SW-L3(config)# interface vlan 10
SW-L3(config-if)# ip address 192.168.10.254 255.255.255.0
SW-L3(config-if)# no shutdown

SW-L3(config)# interface vlan 20
SW-L3(config-if)# ip address 192.168.20.254 255.255.255.0
SW-L3(config-if)# no shutdown

6. Comparatif & Diagnostic rapide

Critère Router-on-a-stick (Routeur 1941) Commutateur Niveau 3 (Catalyst 3560)
Liaison 1 câble trunk entre switch et routeur[cite: 25, 46]. Aucune (routage interne au fond de panier)[cite: 46].
Association VLAN Sous-interface + encapsulation dot1Q[cite: 46]. Interface SVI (interface vlan X) + ip routing[cite: 45, 46].
Débit utile Divisé par 2 sur le lien (aller-retour / hairpin)[cite: 43, 46]. Plein débit matériel (aucun demi-tour)[cite: 46].
  • show ip interface brief : Vérifie que Gi0/0 est unassigned (up/up) et que toutes les sous-interfaces sont up/up[cite: 35].
  • show ip route : Affiche une ligne C (Connected) pour chaque VLAN effectivement routé[cite: 36].
  • tracert 192.168.20.14 (sur PC) : Affiche 2 sauts (la sous-interface du routeur, puis le PC cible) — les switchs L2 restent invisibles[cite: 38].
