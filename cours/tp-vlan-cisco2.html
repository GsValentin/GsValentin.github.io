Le Routage Inter-VLAN : Franchir la Frontière

Router-on-a-stick (sous-interfaces 802.1Q), commutateur de niveau 3 (SVI), trajet des paquets et diagnostic

BTS SIO SISR • Bloc 2 • Commutation & Routage Cisco

1. Pourquoi deux VLANs ne communiquent pas ?

Un VLAN correspond à un domaine de diffusion et donc à un réseau IP distinct[cite: 85]. Un commutateur de niveau 2 (ex. Catalyst 2960) ne lit que les adresses MAC et ne sort jamais du VLAN d'entrée[cite: 84, 85].

  • Sans passerelle sur le poste : Si PC1 (192.168.10.11/24) tente de joindre PC2 (192.168.20.12/24), il détecte que la destination est hors de son réseau, ne trouve aucune passerelle et abandonne immédiatement le paquet avant même qu'il atteigne le câble (message Destination host unreachable et table ARP vide)[cite: 84, 104].
  • Règle fondamentale : Changer de VLAN revient à changer de réseau IP ; il faut obligatoirement un équipement de couche 3 (routeur ou switch L3) pour assurer le routage[cite: 85, 86].

2. Solution 1 : Le Router-on-a-stick

Cette architecture relie un commutateur L2 (SW1) à un routeur (R1) via un seul câble physique configuré en trunk 802.1Q, découpé côté routeur en autant de sous-interfaces logiques qu'il y a de VLANs à router[cite: 86, 87].

A. Côté Commutateur (Port Trunk vers R1)

SW1(config)# interface GigabitEthernet0/2
SW1(config-if)# description Vers R1 trunk inter-VLAN
SW1(config-if)# no shutdown
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk native vlan 999
SW1(config-if)# switchport trunk allowed vlan 10,20,99,150,999
SW1(config-if)# end

Note : Sur un commutateur de niveau 3 (ex. Catalyst 3560), il faut taper switchport trunk encapsulation dot1q avant switchport mode trunk[cite: 88, 105].

B. Côté Routeur (Sous-interfaces 802.1Q)

R1(config)# interface GigabitEthernet0/0
R1(config-if)# no shutdown
R1(config-if)# exit

R1(config)# interface GigabitEthernet0/0.10
R1(config-subif)# encapsulation dot1Q 10
R1(config-subif)# ip address 192.168.10.254 255.255.255.0
R1(config-subif)# exit

R1(config)# interface GigabitEthernet0/0.20
R1(config-subif)# encapsulation dot1Q 20
R1(config-subif)# ip address 192.168.20.254 255.255.255.0
Les 3 règles d'or du Router-on-a-stick :
  • Allumer l'interface physique : Un oubli de no shutdown sur Gi0/0 laisse toutes les sous-interfaces en down[cite: 89, 108].
  • Aucune IP sur Gi0/0 : L'interface physique reste unassigned afin que le trafic non étiqueté du VLAN natif 999 (VLAN mort) soit rejeté[cite: 89, 107, 108].
  • L'encapsulation fait le lien : Le numéro après le point (.10) n'est qu'une convention de nommage ; c'est la commande encapsulation dot1Q 10 qui rattache réellement la sous-interface au VLAN[cite: 89, 108].

C. Passerelle sur les postes ET sur les switches L2

Chaque poste doit recevoir la passerelle de son propre VLAN (ex. 192.168.10.254 pour le VLAN 10)[cite: 90, 110]. De plus, un commutateur de niveau 2 ne route rien, pas même pour lui-même : pour l'administrer depuis un autre VLAN, il faut lui indiquer sa passerelle dans le VLAN de management[cite: 90, 112, 113] :

SW1(config)# ip default-gateway 192.168.99.254

3. Solution 2 : Le Commutateur de Niveau 3 (Switch L3)

Dans un Router-on-a-stick, chaque paquet inter-VLAN traverse deux fois le même câble (montée vers R1 puis descente vers SW1 : effet hairpin ou épingle à cheveux), ce qui divise par deux le débit utile[cite: 94, 116]. Le Switch L3 (ex. Catalyst 3560) intègre directement le routage matériel (ASIC) en interne via des SVI (Switched Virtual Interfaces)[cite: 95, 118] :

SW-L3(config)# ip routing
SW-L3(config)# interface vlan 10
SW-L3(config-if)# ip address 192.168.10.254 255.255.255.0
SW-L3(config-if)# no shutdown
SW-L3(config-if)# interface vlan 20
SW-L3(config-if)# ip address 192.168.20.254 255.255.255.0
SW-L3(config-if)# no shutdown

Attention : Un SVI ne passe en état up/up que si le VLAN existe dans la base et qu'au moins un port actif lui est affecté[cite: 95, 118].

4. Comparatif & Diagnostic des pannes fréquentes

Critère Router-on-a-stick Commutateur de niveau 3
Interfaces routées Sous-interfaces (Gi0/0.10) + encapsulation dot1Q[cite: 96, 119]. Interfaces VLAN virtuelles (SVI : interface vlan 10)[cite: 96, 119].
Débit & Point de panne Débit divisé par 2 (demi-tour sur le câble unique)[cite: 96, 119]. Routage interne au débit du fond de panier (ASIC), sans câble externe[cite: 96, 119].
Sécurité (point de vigilance) Activer le routage ouvre la communication entre tous les VLANs (y compris le VLAN 99 Management)[cite: 97, 120]. Il faudra filtrer les flux avec des ACL[cite: 120].
