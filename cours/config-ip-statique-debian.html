Configuration d'une Adresse IP Statique sous Debian

Paramétrage réseau en ligne de commande (sans interface graphique) via /etc/network/interfaces

BTS SIO SISR • Bloc 2 • Administration Linux

1. Édition du fichier de configuration réseau

Sur une installation Debian serveur (sans environnement graphique), la configuration des cartes réseau s'effectue directement dans le fichier /etc/network/interfaces avec les droits root[cite: 76] :

nano /etc/network/interfaces

2. Paramétrage de l'interface en IP statique

Remplacer ou commenter la configuration DHCP existante sur l'interface concernée (ici ens33) pour lui attribuer une adresse IP fixe[cite: 76] :

# Activation automatique au démarrage
auto ens33

# Configuration IPv4 statique
iface ens33 inet static
    address 10.1.1.1/24
Remarques importantes :
  • Si la notation CIDR (/24) n'est pas indiquée à la suite de l'adresse IP, il faut ajouter la directive netmask 255.255.255.0 sur la ligne suivante[cite: 76].
  • Penser à supprimer ou commenter (avec #) les anciennes lignes allow-hotplug ens33 et iface ens33 inet dhcp, sinon l'interface conserve simultanément son bail DHCP et son IP statique[cite: 76].

3. Redémarrage du service réseau & Vérification

Pour appliquer les modifications sans redémarrer le serveur complet, relancer le démon réseau puis contrôler l'adressage actif[cite: 76] :

# Redémarrer le service réseau
/etc/init.d/networking restart

# Vérifier l'attribution de l'adresse IP sur ens33
ip a

La sortie de ip a doit afficher la ligne inet 10.1.1.1/24 brd 10.1.1.255 scope global ens33[cite: 76].
