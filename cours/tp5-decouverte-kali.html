Découverte de Kali Linux : Reconnaissance & Usurpation MAC

Manipulation de macchanger et Zenmap/Nmap en environnement isolé, analyse des risques et contre-mesures

BTS SIO SISR • Bloc 3 • Cybersécurité Offensive & Défensive
Cadre légal (Art. 323-1 du Code pénal) : Les outils de test d'intrusion intégrés à Kali Linux ne doivent être utilisés que sur un périmètre isolé (machines virtuelles de TP) ou sur des cibles explicitement autorisées comme scanme.nmap.org.

1. Usurpation d'adresse MAC avec macchanger

Situé dans la catégorie Information Gathering / Sniffing & Spoofing de Kali Linux, l'utilitaire macchanger permet de modifier temporairement l'adresse physique (MAC) d'une carte réseau au niveau du système d'exploitation. 

# 1. Désactiver l'interface réseau
sudo ip link set eth0 down

# 2. Attribuer une adresse MAC aléatoire (ou -m XX:XX:XX:XX:XX:XX pour une MAC ciblée)
sudo macchanger -r eth0

# 3. Réactiver l'interface réseau
sudo ip link set eth0 up
  • Dangers : Contournement d'un filtrage par adresse MAC (Wi-Fi ou switch), usurpation d'identité sur le réseau local, saturation de la table CAM d'un commutateur (MAC Flooding) ou épuisement d'un serveur DHCP.
  • Contre-mesures : Activer le Port Security sur les commutateurs Cisco (switchport port-security), déployer l'authentification réseau 802.1X (RADIUS) et activer le DHCP Snooping.

2. Cartographie réseau avec Zenmap (zenmap-kbx / Nmap)

L'application zenmap-kbx lance Zenmap (l'interface graphique de Nmap) dans un environnement conteneurisé Kaboxer. Elle permet d'automatiser la phase de reconnaissance active sur un réseau :

Fonctionnalité Nmap / Zenmap Option CLI Information révélée
Découverte d'hôtes nmap -sn 192.168.1.0/24 Liste les machines allumées qui répondent sur le sous-réseau.
Scan furtif TCP SYN sudo nmap -sS <IP> Identifie les ports TCP ouverts, fermés ou filtrés sans terminer la poignée de main TCP.
Détection de versions & OS sudo nmap -sV -O <IP> Détermine les logiciels exacts en écoute et le système d'exploitation cible.
  • Dangers : Permet à un attaquant d'identifier la surface d'attaque (ports ouverts, services obsolètes ou non chiffrés) avant de rechercher des failles exploitables.
  • Contre-mesures : Fermer tous les ports inutiles via un pare-feu (Windows Defender Firewall, ufw/nftables), segmenter le réseau en VLANs filtrés par ACL et déployer une sonde IDS/IPS (Suricata, Fail2Ban).
