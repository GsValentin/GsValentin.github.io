Raccourcis Console Windows (Win + R)

ncpa.cpl

Ouvre directement les connexions réseau (cartes Ethernet, Wi-Fi, configuration IPv4).

Réseau & Diagnostic (CMD / PowerShell)

gpupdate /force

Force l'actualisation immédiate des stratégies de groupe (GPO) utilisateur et ordinateur.

Administration Linux (Debian / Ubuntu)

ip a

Affiche les interfaces réseau et leurs adresses IP attribuées.

grep -c "ERROR" fichier.log

Compte le nombre de lignes contenant le mot-clé ERROR dans un fichier de logs[cite: 72].

grep -iv "info" fichier.log

Affiche toutes les lignes ne contenant pas « info » (insensible à la casse, inverse le filtre)[cite: 73].

grep -iE "connection lost" fichier.log

Recherche un motif avec expressions régulières étendues (-E) sans tenir compte des majuscules (-i)[cite: 72].

grep '^\[DEBUG\]' fichier.log | grep -w 'user'

Filtre les lignes commençant par [DEBUG] puis isole celles contenant le mot exact « user » via un tube (pipe)[cite: 75].

grep " 08:" fichier.log

Filtre les événements survenus sur une plage horaire précise (ici à 08h) dans un journal[cite: 75].

Administration Switch & VLAN (Cisco IOS)

show vlan brief

Affiche tous les VLANs configurés, leur statut et les ports en mode access associés.

show interfaces trunk

Vérifie les liens trunk actifs, l'encapsulation 802.1Q, le VLAN natif et les VLANs autorisés.

show interfaces fa0/1 switchport

Affiche le détail complet d'un port (mode admin/opérationnel, VLAN access, VLAN natif et VLAN voix).

show mac address-table

Consulte la table des adresses MAC apprises par le commutateur, classées par numéro de VLAN.

switchport mode access

Force un port en mode accès (un seul VLAN de données, désactive la négociation trunk).

switchport access vlan 10

Affecte le port actif au VLAN spécifié (ici le VLAN 10).

switchport voice vlan 150

Ajoute un VLAN voix dédié sur un port access accueillant un téléphone IP et un PC.

switchport mode trunk

Configure le port en lien trunk (transport multi-VLANs étiquetés 802.1Q entre équipements).

switchport trunk native vlan 999

Définit le VLAN natif (trafic non étiqueté) sur un VLAN vide dédié pour sécuriser le trunk.

switchport trunk allowed vlan 10,20,99

Restreint le passage sur le trunk uniquement aux VLANs listés.

interface range fastEthernet 0/3-24

Sélectionne une plage de ports pour les configurer ou les éteindre (shutdown) simultanément.

encapsulation dot1Q 10

Associe une sous-interface de routeur (ex: Gi0/0.10) aux trames étiquetées du VLAN 10.

ip default-gateway 192.168.99.254

Définit la passerelle par défaut d'un commutateur de niveau 2 pour l'administrer depuis un autre VLAN.

ip routing

Active la fonction de routage IP sur un commutateur de niveau 3 (ex: Catalyst 3560) pour router entre ses SVI.

show ip route

Affiche la table de routage d'un routeur ou switch L3 (les réseaux connectés apparaissent avec le code C).

show interfaces gigabitEthernet 0/0 | include packets

Filtre les statistiques d'une interface Cisco pour afficher uniquement les compteurs de paquets entrants et sortants.

copy running-config startup-config

Sauvegarde la configuration active (RAM) dans la mémoire non volatile (NVRAM) du switch ou routeur.
