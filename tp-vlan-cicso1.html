Segmentation Réseau & VLANs Cisco

Ports Access, lien Trunk 802.1Q, VLAN natif, Management (SVI) et VoIP sur Catalyst 2960

BTS SIO SISR • Cisco Packet Tracer

1. Distinction fondamentale : Mode de port vs Rôle de VLAN

Un commutateur neuf place tous ses ports dans le VLAN 1 (default)[cite: 9]. Segmenter le réseau consiste à découper le switch en domaines de diffusion étanches sans ajouter de matériel[cite: 5, 6].

Règle de vocabulaire : On ne dit jamais « un VLAN trunk » ou « un VLAN access »[cite: 6]. Access et Trunk sont des modes de port (trames non étiquetées vs étiquetées 802.1Q)[cite: 6, 14]. Données, Management, Voix, Natif et Mort sont des rôles de VLAN[cite: 6].

2. Plan des VLANs & Adressage de la maquette

N° VLAN Nom Rôle & Sécurité Sous-réseau / Équipements
1 default VLAN d'usine. Doit être entièrement vidé (aucun port actif)[cite: 5, 9]. —
10 DIRECTION VLAN de données (Direction)[cite: 5]. 192.168.10.0/24 (PC1, PC3)[cite: 5, 6]
20 COMPTA VLAN de données (Comptabilité)[cite: 5]. 192.168.20.0/24 (PC2, PC4)[cite: 5, 6]
99 MGMT Administration à distance des switchs (SVI). Isolé des utilisateurs[cite: 5, 17]. 192.168.99.0/24 (SW1: .1, SW2: .2, PC-ADMIN: .10)[cite: 7]
150 VOIX Trafic des téléphones IP (priorisé et isolé des PC)[cite: 5, 19]. IP Phone 7960 (derrière SW1 Fa0/2)[cite: 6, 7]
999 MORT VLAN natif du trunk et parking des ports inutilisés (shutdown)[cite: 5, 21]. Ports libres (Fa0/3-4, Fa0/6-24, Gi0/2)[cite: 21]

3. Création des VLANs & Ports Access

Un VLAN doit être déclaré sur chaque commutateur qu'il traverse[cite: 10]. Sur un port utilisateur, on fixe toujours le mode access avant d'attribuer le VLAN pour éviter toute négociation DTP[cite: 12].

! 1. Création des VLANs (à répéter sur SW1 et SW2)
SW1(config)# vlan 10
SW1(config-vlan)# name DIRECTION
SW1(config-vlan)# vlan 20
SW1(config-vlan)# name COMPTA
SW1(config-vlan)# vlan 99
SW1(config-vlan)# name MGMT
SW1(config-vlan)# vlan 150
SW1(config-vlan)# name VOIX
SW1(config-vlan)# vlan 999
SW1(config-vlan)# name MORT
SW1(config-vlan)# exit

! 2. Affectation d'un port utilisateur (mode access)
SW1(config)# interface fastEthernet 0/1
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 10

4. Lien Trunk 802.1Q & VLAN Natif

Le lien inter-switch (Gig0/1, relié par câble croisé) transporte plusieurs VLANs en étiquetant les trames[cite: 8, 14]. Le VLAN natif (seul trafic non étiqueté) est déplacé vers le VLAN vide 999 pour contrer les attaques par VLAN hopping[cite: 14, 15].

SW1(config)# interface gigabitEthernet 0/1
SW1(config-if)# switchport mode trunk
SW1(config-if)# switchport trunk native vlan 999
SW1(config-if)# switchport trunk allowed vlan 10,20,99,150,999
Note matériel : Sur un Catalyst 2960, la commande switchport trunk encapsulation dot1q est refusée car ce modèle ne gère nativement que la norme 802.1Q (contrairement aux switchs L3 gérant aussi ISL)[cite: 14].

5. Management (SVI), VoIP & Durcissement

Interface virtuelle d'administration (SVI)

SW1(config)# interface vlan 99
SW1(config-if)# ip address 192.168.99.1 255.255.255.0
SW1(config-if)# no shutdown

Port hybride Données + Voix (Téléphone IP + PC)

Un port reste en static access mais porte deux VLANs : les trames non étiquetées du PC vont dans le VLAN 20, tandis que le téléphone étiquette ses paquets voix en 150 (appris via CDP)[cite: 19].

SW1(config)# interface fastEthernet 0/2
SW1(config-if)# switchport mode access
SW1(config-if)# switchport access vlan 20
SW1(config-if)# switchport voice vlan 150

Neutralisation des ports inutilisés (Double barrière)

SW1(config)# interface range fastEthernet 0/6-24
SW1(config-if-range)# switchport mode access
SW1(config-if-range)# switchport access vlan 999
SW1(config-if-range)# shutdown

6. Commandes de diagnostic & Preuve d'isolation

  • show vlan brief : Vérifie l'existence des VLANs et les ports access associés (un port trunk n'y apparaît jamais)[cite: 22, 23].
  • show interfaces trunk : Contrôle l'état trunking, le VLAN natif et les VLANs autorisés/actifs[cite: 15, 23].
  • show interfaces fa0/2 switchport : Affiche le mode administratif, le mode opérationnel, le VLAN access et le VLAN voix[cite: 13, 19].
  • show mac address-table : Montre que le commutateur maintient une table CAM distincte par VLAN[cite: 23].

Conclusion réseau : Deux postes ayant la même plage IP (ex. 192.168.10.13 et 192.168.10.14) sur le même switch mais dans deux VLANs différents (10 et 20) ne peuvent pas communiquer : le switch isole le trafic au niveau 2 (liaison) avant même d'analyser les adresses IP[cite: 24].
